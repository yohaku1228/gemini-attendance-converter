# 勤怠コンバーター

Gemini APIで手書き・印刷された勤怠PDF／PNG／JPEGを読み取り、編集してExcel（.xlsx）・CSVに出力する単一HTMLのWebツールです。

## 使い方

1. `index.html` をダウンロードしてブラウザーで開きます。CDNの読み込みとAPI通信にインターネット接続が必要です。
2. 自分のGemini APIキーと利用可能なモデル名を入力します。
3. 「接続テスト」でキーとモデルのテキスト生成を確認します。
4. PDFまたは画像を追加します。必要に応じて対象年月を指定して「AI解析を開始」を押します。
5. 原本と照合し、表のセルを修正してExcel／CSVを出力します。

初期モデル名は画面の指定に合わせた `gemini-3.5-flash-lite` です。利用可能なモデル名に変更してください。モデルの利用可否は接続テストで確認できます。

## 機能

- 複数PDF・PNG・JPEGのドラッグ＆ドロップ
- PDF.jsによるページ単位の画像化、Geminiの構造化JSONによる抽出
- 進捗表示・中止・失敗ページの再試行
- 原本表示、セル編集、検索、要確認フィルター、100行単位の表示
- SheetJSによるExcel生成、UTF-8 BOM付きCSV出力
- APIキーの任意保存・削除、接続テスト

## データの扱い

- 書類の画像は解析時にGoogle Geminiに送信されます。APIキーは認証ヘッダーで送信されます。
- 接続テストでは短いテキストのみ送信し、書類は送信しません。API利用枠を使用します。
- APIキーの保存を選択した場合、LocalStorageに保存されます。共有端末では保存しないでください。
- 勤怠データはブラウザーのメモリー内で処理します。閉じる前にダウンロードしてください。
- APIキーや実際の勤怠書類・抽出結果をリポジトリにコミットしないでください。
- OCRの誤読があり得るため、給与計算などに使う前に必ず原本と照合してください。

## 構成・検証状況

ビルド不要です。Tailwind CSS、Lucide、PDF.js、SheetJSをCDNから読み込みます。

デモで検索・フィルターとExcel／CSVダウンロードを確認しています。接続テストは模擬応答で成功・主要エラーを確認済みです。実APIでのOCR精度・大量原稿の検証は、ご自身のAPIキーと原稿で行ってください。

GitHub Pagesで配信する場合は `index.html` を配置したブランチのルートを公開元に設定します。リポジトリへの登録だけではサイト配信は有効になりません。
